## 🚀 Projekty

### ⭐ Hlavní: Classmate

> **[Classmate](https://classmate.cz)** je aplikace pro celou třídu nebo školu propojená s **Bakaláři**.

Rozvrh se změnami v reálném čase, společné úkoly a testy, kalendář, známky a poznámky s nahrávkami z hodin jsou na jednom místě. Funguje na telefonu i počítači jako **PWA**, bez reklam, s **dvoufázovým ověřením** a s podporou AI asistentů přes **MCP**.
