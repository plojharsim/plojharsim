## 👋 O mně

Jsem **Šimon**, 16letý student **SSPŠ** z Česka. Programování mě baví nejvíc ze všeho. Nejradši vymýšlím a stavím věci, které fungují doopravdy: webové aplikace, weby pro skutečné lidi a firmy a občas i nástroje, které si pustím doma na vlastním serveru.

- 🌐 Vyvíjím moderní weby a aplikace v **React + TypeScript**
- ☁️ Backendy stavím na **Supabase** a **Node.js**
- 📱 Zkouším i mobilní aplikace přes **Capacitor**
- 🖥️ Doma provozuju vlastní **Proxmox** home server (HP t640)
- 🎮 Když zrovna nekóduju, hraju hry
- 🇨🇿 Většinu projektů dělám česky a pro české uživatele

> 💡 **Aktuálně:** vylepšuju svoje portfolio, dělám na Edu (učení do školy zábavnou formou) a stavím vlastní self-hostované nástroje.
